# ping-pong

в данном репозитории лежит прототип игры "ping-pong". это мультиплеерная игра для двух игроков.

прототип игры выполнен на языке Python, с помощью библиотеки Pygame.

первый игрок управляет левой ракеткой, второй игрок правой. игрок проигрывает как только мяч касается стены позади него.
